# goit-js-hw-07

Домашнє завдання №7 — «Модель DOM. Події».

## Завдання

| #   | Сторінка      | Скрипт         | Опис                                                      |
| --- | ------------- | -------------- | --------------------------------------------------------- |
| 1   | `task-1.html` | `js/task-1.js` | Підрахунок категорій та елементів у них, вивід у консоль  |
| 2   | `task-2.html` | `js/task-2.js` | Галерея зображень із масиву об'єктів                      |
| 3   | `task-3.html` | `js/task-3.js` | Привітання за значенням інпута (подія `input`)            |
| 4   | `task-4.html` | `js/task-4.js` | Форма логіна (подія `submit`, валідація, `reset`)         |
| 5   | `task-5.html` | `js/task-5.js` | Зміна кольору фону `<body>` по кліку                      |
| 6   | `task-6.html` | `js/task-6.js` | Створення та видалення колекції різнокольорових квадратів |

## Структура

```
index.html        — сторінка зі списком посилань на завдання
task-1..6.html    — сторінки завдань
css/common.css    — спільні стилі
js/task-1..6.js   — скрипти завдань
```

## Форматування

Код відформатовано за допомогою Prettier (конфіг — `.prettierrc.json`):

```bash
npm install
npx prettier --write .
```
